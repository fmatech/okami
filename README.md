# Okami

Landing page pública institucional da Okami.

## Marca base

- Empresa focada em inovações tecnológicas para pequenas e médias empresas, com ênfase em IA
- Paleta principal: preto, laranja, magenta, ciano e branco
- Tagline visível no logo: `CUSTOM SOLUTIONS. AI INNOVATION.`

## Ativos de referência

- `assets/brand/okami-logo-light.jpg`: variante para fundos claros
- `assets/brand/okami-logo-dark.jpg`: variante para fundos escuros

## Estrutura atual

- `index.html`: landing page institucional single-page
- `styles.css`: sistema visual e responsividade da landing
- `assets/brand/`: ativos de marca usados como referência visual

## Direção de implementação atual

A primeira versão da landing foi construída com foco em:

- contraste alto e presença premium
- identidade visual cyber com uso controlado de laranja, magenta e ciano
- copy institucional clara para posicionamento da Okami
- estrutura semântica simples, responsiva e fácil de evoluir
- base estática adequada para revisão visual e evolução posterior

## Publicação local

Como a base atual é estática, a página pode ser aberta diretamente no navegador ou servida localmente com um servidor HTTP simples.

Exemplo:

```bash
python3 -m http.server 4281
```

Depois, abrir:

```text
http://127.0.0.1:4281/index.html
```

## Objetivo deste repositório

Servir de base para desenvolvimento, UX, revisão e publicação da landing page pública da Okami.
